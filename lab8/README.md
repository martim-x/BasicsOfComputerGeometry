# Лабораторная работа № 8 – поверхности второго порядка (C++ / Win32)

## Цель

Построить три поверхности `z=f(x,y)` в аксонометрической проекции и упорядочивать их треугольные участки по глубине от дальних к ближним (алгоритм художника).

## Требования → реализация → что изучено

| Требование | Реализация | Результат |
|---|---|---|
| Эллиптический параболоид `z=x²+y²`, `x,y∈[-5,5]`, шаг 0.25 | `SurfaceCore::EvaluateSurface` и `BuildSurface` | 3200 треугольников сетки |
| Гиперболический параболоид `z=x²−y²`, тот же диапазон и шаг | Отдельный вариант `SurfaceKind::HyperbolicParaboloid` | 3200 треугольников сетки |
| Верхняя полусфера радиуса 3, `z≥0`, `x,y∈[-3,3]`, шаг 0.25 | `EvaluateSurface` отвергает точки вне круга, а на границе сетки используются пересечения рёбер ячеек с окружностью | Сетка доходит до экватора; вершины за пределами сферы не рисуются |
| Сортировка по глубине | `SortFarToNear` сортирует треугольные участки от дальних к ближним | При ортографическом отображении перекрывающиеся части закрашиваются в порядке художника |
| Камера и меню выбора | Все пять команд находятся в меню «Фигура», как на рис. 1 методички | При запуске видны только углы; после изменения камеры выбранная поверхность перерисовывается |

## Теория

При алгоритме художника полигоны рисуются от самых дальних к самым близким: более близкие полигоны затем перекрывают дальние. Для поверхностей `z=f(x,y)` лекция описывает построение дискретной матрицы значений и сортировку по глубине (глава 12.2.2, печатные стр. 143–144). В этой реализации сеточные ячейки разбиваются на треугольники и сортируются по средней глубине вершин относительно направления камеры.

Сортировка по средней глубине – учебное приближение: она не разрешает все случаи неоднозначного перекрытия. У камеры фиксированный радиус 10, начальные углы 45° и 45°. При ортографической проекции расстояние до камеры не меняет экранные координаты или порядок, поэтому достаточно направления, заданного углами.

```bash
clang++ -std=c++17 -Wall -Wextra -Werror -I lab8 \
  lab8/tests/SurfaceCoreTests.cpp lab8/SurfaceCore.cpp \

/tmp/lab8-core-tests
```

Проверяются формулы, число треугольников параболоидов, экватор и уравнение полусферы, порядок рисования по глубине и обработка корректных и ошибочных углов.

## Сборка и запуск в Visual Studio

1. Открой `lab8.sln` в Visual Studio с набором C++ `v145` и Windows SDK.
2. Выбери `Release | ARM64` или `Release | x64` и собери решение.
3. Запусти приложение (`Ctrl+F5`). В левом верхнем углу будут видны текущие углы; поверхность появится после выбора в меню «Фигура».
4. Чтобы изменить ракурс, отредактируй `angles.txt` **рядом с `lab8.exe`** и выбери «Фигура» → «Положение камеры». В файле два числа: азимут и зенит в градусах. Для дробных значений используй точку, зенит должен быть в диапазоне 0–180°. Сборка создаёт этот файл, только если его ещё нет.
5. «Фигура» → «Положение камеры по умолчанию» возвращает 45°/45°, не меняя выбранную поверхность.
