# Лабораторная работа № 8 — поверхности второго порядка (C++ / MFC)

## Цель

Построить три поверхности `z=f(x,y)` в аксонометрической проекции и упорядочивать их треугольные участки по глубине от дальних к ближним (алгоритм художника).

## Требования → реализация → что изучено

| Требование | Реализация | Результат |
|---|---|---|
| Эллиптический параболоид `z=x²+y²`, `x,y∈[-5,5]`, шаг 0.25 | `SurfaceCore::EvaluateSurface` и `BuildSurface` | 3200 треугольников сетки |
| Гиперболический параболоид `z=x²−y²`, тот же диапазон и шаг | Отдельный вариант `SurfaceKind::HyperbolicParaboloid` | 3200 треугольников сетки |
| Верхняя полусфера радиуса 3, `z≥0`, `x,y∈[-3,3]`, шаг 0.25 | `EvaluateSurface` отвергает точки вне круга; ячейка пропускается, если хотя бы один угол не принадлежит поверхности | 784 треугольника; отрицательный подкоренной аргумент не вычисляется |
| Сортировка по глубине | `SortFarToNear` сортирует треугольные участки от дальних к ближним | При ортографическом отображении перекрывающиеся части закрашиваются в порядке художника |
| Камера и меню выбора | Меню приложения выбирает поверхность, читает углы из `angles.txt` и возвращает камеру к значениям по умолчанию | После изменения камеры выбранная поверхность перерисовывается |

## Теория

При алгоритме художника полигоны рисуются от самых дальних к самым близким: более близкие полигоны затем перекрывают дальние. Для поверхностей `z=f(x,y)` лекция описывает построение дискретной матрицы значений и сортировку по глубине (глава 12.2.2, печатные стр. 143–144). В этой реализации сеточные ячейки разбиваются на треугольники и сортируются по средней глубине вершин относительно направления камеры.

Сортировка по средней глубине — учебное приближение: она не разрешает все случаи пересекающихся поверхностей. Лекция отдельно отмечает это ограничение и необходимость модификаций для неоднозначного порядка.

## Проверки на macOS

```bash
clang++ -std=c++17 -Wall -Wextra -Werror -I lab8 \
  lab8/tests/SurfaceCoreTests.cpp lab8/SurfaceCore.cpp \
  -o /tmp/lab8-core-tests
/tmp/lab8-core-tests
```

Проверяются значения функций, область полусферы, число сеточных треугольников, лежание полусферы на `x²+y²+z²=9` и порядок рисования по глубине.

## Сборка и запуск в Visual Studio

1. Открой `lab8.sln`.
2. Выбери `Release | ARM64` или `Release | x64` и собери решение.
3. Запусти `lab8.exe` из каталога, где доступен `angles.txt`.
4. В меню «Фигура» выбери одну из трёх поверхностей. В меню «Камера» можно загрузить два угла из `angles.txt` или вернуть значения 45°/45°.

**Статус проверки:** математическое ядро собрано и тесты прошли на macOS. MFC-проект и реальное окно в Visual Studio пока не собраны и не запущены; это остаётся обязательной проверкой на Windows.
