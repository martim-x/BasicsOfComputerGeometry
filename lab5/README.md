# Лабораторная работа № 5 — «Лопасть» (C++ / MFC)

Аффинные преобразования на плоскости: вращение объекта «Лопасть» вокруг центра.

## Задание

- Реализовать `CreateTranslate2D`, `CreateRotate2D` в библиотеке (`LibBlade.cpp`).
- Класс `CBlade`: параметры фигуры задаются в конструкторе по умолчанию.
- Пункт меню «LabBlade ► Blade» выводит статичное изображение.
- Вращение выполняется объектом Windows «Таймер».

## Что сделано сверх задания

- Лопасть имеет форму `. |>`: плоское основание обращено к центру, остриё — наружу.
- Количество лопастей задаётся графически (2–12), лопасти распределяются равномерно.
- Угловая скорость задаётся графически (0–360 °/с), вращение идёт по часовой стрелке.
- Одиночный клик по зелёной центральной втулке включает вращение, следующий клик — останавливает.
- Угол пересчитывается по реальному времени между кадрами (`GetTickCount`), поэтому скорость
  не зависит от загрузки таймера.

## Сборка

Открыть `lab5.sln` в Visual Studio (платформа x64 или Win32, набор инструментов v143),
конфигурация Debug/Release → F5.

## Файлы

| Файл | Назначение |
|---|---|
| `LibBlade.cpp` | матрицы преобразований, `CBlade`: хранение угла, отрисовка |
| `BladeGeometry.cpp` | чистая математика формы лопасти и шага угла (без MFC) |
| `ChildView.cpp` | окно, ползунки, таймер, обработка клика по втулке |
| `lab5.cpp`, `MainFrm.cpp` | каркас MFC-приложения |
| `tests/lab5-blade-geometry-tests.cpp` | тесты формы лопасти и вращения (собираются clang++) |

clang++ -std=c++17 -Wall -Wextra -Werror tests/lab5-blade-geometry-tests.cpp lab5/BladeGeometry.cpp \
