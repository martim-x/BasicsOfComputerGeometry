# Lab 11 — построение кривых на плоскости (C++ / MFC)

## Цель и требования

Реализованы интерполяция Лагранжа и геометрический алгоритм построения кривых Безье. Методичка задаёт функцию `Lagr(CMatrix&, CMatrix&, double)`, функцию `Bezier(CMatrix&, CMatrix&, CMatrix&, CMatrix&, int)`, два пункта меню и экспорт координат в текстовые файлы для Mathcad.

## Что сделано

| Требование | Реализация | Проверяемый результат |
|---|---|---|
| Интерполяция набора `(X,Y)` | `Lagr` в `CurveCore.cpp` | Возвращает значения исходных узлов и интерполирует между ними |
| Данные из задания | `f(x)=[2+cos(x)]^sin(2x)`, `x∈[0,π]`, `Δx=π/4` | 5 узлов, узлы отображаются точками |
| График Лагранжа | `CPlot2D` | Кривая рассчитывается при `Δx=0.2`; `π` добавляется как последний конец отрезка |
| Геометрический алгоритм Безье | `Bezier` и `BezierPoints` | Последовательные уровни линейной интерполяции; `M` сегментов дают `M+1` точек, включая `t=0` и `t=1` |
| Варианты из рис. 14.5 | Меню `Lines → Bezier` | Квадратичная кривая по 3 опорным точкам и кубическая по 4; на графике показаны их опорные ломаные и кривые |
| Передача данных в Mathcad | `WritePointFile` | Два числовых столбца, разделённых табуляцией, без заголовка |

## Теория

Полином Лагранжа вычисляется как сумма базисных полиномов:

`L(x)=Σᵢ yᵢ Πⱼ≠ᵢ (x−xⱼ)/(xᵢ−xⱼ)`.

При попарно различных узлах он проходит через каждую заданную точку. Реализация возвращает исходное `yᵢ`, когда аргумент точно совпадает с узлом, и отклоняет неупорядоченные/повторяющиеся `x`, несовпадающие размеры векторов и аргумент вне `[x₀,xₙ]`.

Алгоритм Безье строит промежуточные точки линейной интерполяцией соседних точек при одном и том же `t`; каждый следующий уровень содержит на одну точку меньше. Последняя оставшаяся точка — точка кривой. Именно эта схема реализована в `BezierPoints`; формулы полинома Бернштейна для обхода требования геометрического алгоритма не применяются.

Источник: `lectures/Основы КГиГ_New_12_Disk_Лекции_1.pdf`, §14.3 (интерполяция Лагранжа, печатные с. 160–162) и §14.5.1–14.5.2 (Безье и геометрический алгоритм, печатные с. 168–170). В методичке Lab 11 у графиков рис. 14.5 указаны `m=2, t=0.5` и `m=3, t=0.5`, но числовые координаты опорных точек не приведены. Поэтому конкретные координаты двух наборов в меню выбраны в коде как наглядные примеры соответствующих степеней; их можно изменить в `OnBezier`.

## Управление и файлы экспорта

- `Lines → Lagr` — строит интерполяционный график и записывает:
  - `Mathcad/lagrange_data.txt` — 5 исходных точек;
  - `Mathcad/lagrange_curve.txt` — значения полинома с шагом 0.2 и включённой конечной точкой `π` (17 строк).
- `Lines → Bezier` — строит обе кривые и записывает:
  - `Mathcad/bezier_2_control.txt`, `Mathcad/bezier_2_curve.txt`;
  - `Mathcad/bezier_3_control.txt`, `Mathcad/bezier_3_curve.txt`.
- Для кривых Безье выбрано `M=100`, поэтому каждый файл кривой содержит 101 точку. Ввод данных задан вручную в обработчике меню, что допускает условие.
- В `Mathcad/` включены готовые числовые таблицы для импорта; выбор пункта меню перезаписывает их, используя те же исходные данные и функции ядра.
- График автоматически подстраивает рамку и шкалы при изменении размера окна.

```bash

  lab11/tests/CurveCoreTests.cpp lab11/CurveCore.cpp \
  -o /tmp/lab11-core-tests
/tmp/lab11-core-tests
```
