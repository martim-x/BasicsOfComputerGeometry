# Лабораторная работа № 10 — освещение шара (C++ / MFC)

## Цель

Показать шар радиуса 2 как набор точек поверхности и сравнить диффузную модель отражения с зеркальной.

## Требования → реализация → что изучено

| Требование | Реализация | Результат |
|---|---|---|
| Камера `(15, 30°, 60°)` | `camera.txt`, меню «Камера» | Положение наблюдателя задаётся отдельно от источника |
| Источник `(10, 45°, 45°)`, цвет по умолчанию жёлтый | `light.txt`, меню «Источник света», RGB-диалог | Изменение параметров обновляет текущий режим |
| Вычисление точек сферы по углам | `SampleSphere`, шаги `Δφ=Δθ=2°` | На каждом полюсе сохраняется одна точка, без дублирования меридианов |
| Диффузное освещение | `Kd·max(0,N̂·L̂)` | Световая интенсивность зависит от угла падения |
| Зеркальное освещение | `Ks·max(0,R̂·V̂)^p` с отражённым вектором `R̂` | Отдельный узкий блик; режим не подменяется расчётом диффузного света |
| Вывод точек и видимой полусферы | `DrawLightSphere` и проверка нормали к камере | На экране остаются точки, обращённые к наблюдателю |

## Теория

Диффузная составляющая зависит от косинуса угла между нормалью сферы и направлением на источник. Зеркальная составляющая зависит от совпадения направления идеального отражения с направлением на наблюдателя. Эти модели рассмотрены в лекции, глава 13.1–13.2, печатные стр. 148–153.

В реализации заданы коэффициенты `Kd=0.8`, `Ks=0.8` и показатель блеска `p=24`; коэффициенты и степень не заданы в условии, поэтому это параметры реализации. Фоновый свет не добавлен: в затенённых областях выбранная модель может давать чёрный цвет.

## Управление

- **Фигура → Шар → Диффузная модель** — показать сферу по модели Ламберта.
- **Фигура → Шар → Зеркальная модель** — показать зеркальный блик.
- **Камера → Положение из camera.txt** и **Источник света → Положение из light.txt** — перечитать по три числа `r азимут зенит`; экран обновляется без повторного выбора модели.
- **Цвет источника…** — выбрать цвет.
- Пункты «По умолчанию» восстанавливают значения из задания.

Начальные параметры: радиус шара 2, камера `(15,30°,60°)`, источник `(10,45°,45°)`, цвет источника `RGB(255,255,0)`.

## Файлы

| Файл | Назначение |
|---|---|
| `lab10.sln`, `lab10.vcxproj` | MFC-проект Visual Studio |
| `SphereLightingCore.h/.cpp` | Сферическая сетка, видимость точек и расчёт двух моделей освещения без MFC |

| `tests/SphereLightingTests.cpp` | Проверки сетки, полюсов, видимости, интенсивностей и цвета |
| `camera.txt`, `light.txt` | Параметры камеры и источника света |

## Проверки на macOS

```bash
clang++ -std=c++17 -Wall -Wextra -Werror -I lab10 \
  lab10/tests/SphereLightingTests.cpp lab10/SphereLightingCore.cpp \
  -o /tmp/lab10-core-tests
/tmp/lab10-core-tests
```

Проверяются радиус точек, единичная длина нормалей, отсутствие дублирующихся полюсов, освещение при совпадающих/противоположных направлениях, зеркальный блик и преобразование начальных сферических координат.

## Сборка и запуск в Visual Studio

1. Открой `lab10.sln`.
2. Выбери `Release | ARM64` или `Release | x64` и собери решение.
3. Запусти `lab10.exe` из каталога, где доступны `camera.txt` и `light.txt`.
4. Выбери диффузную или зеркальную модель; затем проверь изменения камеры, источника и цвета.

**Статус проверки:** математическое ядро собрано и тесты прошли на macOS. MFC-проект и реальное окно в Visual Studio пока не собраны и не запущены; это остаётся обязательной проверкой на Windows.
