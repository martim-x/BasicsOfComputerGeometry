## Вопрос 2. Что такое система координат

Система координат (СК) — способ задания положения точки в пространстве (на плоскости) набором чисел — координат, относительно выбранного начала отсчёта и набора базисных направлений (осей). Точка `P` соответствует упорядоченному набору чисел `(x, y)` в 2D или `(x, y, z)` в 3D. Выбор СК определяет, как объекты описываются, преобразуются и отображаются.

---

## Вопрос 3. Какие системы координат мы знаем (4 системы из лекций, гл. 7.1)

1. **Декартова (прямоугольная)** СК — `P=(x,y)` на плоскости, `P=(x,y,z)` в пространстве. Оси `OX, OY, (OZ)` взаимно перпендикулярны, начало в точке `O`. Тройка базисных ортов: i, j, k. Правая система: при повороте `i → j` на `π/2` вектор `k` совпадает с поступательным движением винта с правой резьбой.

2. **Полярная** СК (2D) — точка `P=(r,φ)`: `r∈[0,∞)` — полярный радиус, `φ` — полярный угол (азимут), отсчитываемый от полярной оси против часовой стрелки (`φ∈(-π,π]` или `[0,2π)`). Связь с декартовыми (формула 7.1.1):

```
x = r·cos(φ),  y = r·sin(φ).
```


3. **Цилиндрическая** СК (3D) — точка `P=(ρ,φ,z)`: `ρ=√x^2+y^2` — расстояние до оси `OZ`, `φ` — угол в плоскости `XOY`, `z` — высота. Связь с декартовыми:

```
x = ρ·cos(φ),  y = ρ·sin(φ),  z = z.
```


4. **Сферическая** СК (3D) — точка `P=(r,φ,θ)`: `r` — расстояние от начала координат до `P` (`0≤ r<∞`); `φ∈(0,2π]` — угол между `OX` и проекцией `OP` на плоскость `XOY`; `θ∈[0,π]` — угол между `OZ` и отрезком `OP`. Связь с декартовыми (формула 7.1.2):

```
x = r·sin(θ)·cos(φ),  y = r·sin(θ)·sin(φ),  z = r·cos(θ).
```


**Примечание.** Мировая (МСК) и оконная (экранная) системы координат — это не отдельные системы координат, а применение одной и той же декартовой СК в двух разных областях: мировой (истинное положение объектов) и устройственной (пиксели экрана/окна). Аналогично логическая СК — декартова СК с единицами, зависящими от режима отображения GDI.

## Вопрос 4. Какая система координат использовалась в лабе

В ЛР 2 использовалась **декартова СК** в двух областях: мировой (МСК) и оконной (экранной).

- В МСК задана фигура (многоугольник `ABCDE`, точки `F,H`) и функция `f(x)=sin(π x)√|x|`.
- Область вывода задана в оконных (пиксельных) координатах: `D_w = (x_L^w, y_L^w, x_H^w, y_H^w)`.
- Границы мировой области `D` определяются по габаритам объекта: `(x_L,y_H)=(x_min,y_max)`, `(x_H,y_L)=(x_max,y_min)`.
- Пересчёт выполняется матрицей `T` (в MathCad — `Tsw`), см. сигнатуру ниже.

---

## Общая сигнатура пересчёта (мировые 2D `→` оконные)

**Дано:**

```
D=(x_L, y_L, x_H, y_H) (область в МСК), D_w=(x_L^w, y_L^w, x_H^w, y_H^w) (область окна, пикселы).
```


**Шаг 1.** Ширины/высоты областей:

```
Δ x = x_H-x_L, Δ y = y_H-y_L, Δ x_w = x_H^w-x_L^w, Δ y_w = y_H^w-y_L^w.
```


**Шаг 2.** Масштабные коэффициенты:

```
k_x = Δx_w / Δx,  k_y = Δy_w / Δy.
```


**Шаг 3.** Матрица пересчёта (однородные координаты):

```
T = [[ k_x,  0,  x_L^w - k_x·x_L ],
     [ 0,  -k_y,  y_H^w + k_y·y_L ],
     [ 0,   0,    1              ]],
   (x_w, y_w, 1)^T = T · (x, y, 1)^T.
```


**Шаг 4.** Формулы пересчёта точки:

```
x_w = k_x·(x - x_L) + x_L^w,   y_w = -k_y·(y - y_L) + y_H^w.
```

Минус перед `k_y` — инверсия оси `Y` (в МСК `Y` растёт вверх, в оконной СК — вниз).

**Шаг 5.** Построить объект по `(x_w,y_w)` в `D_w`.

## Задание 1 — фигура ABCDE (F, H)

Координаты вершин (МСК):

| точка | A | B | C | D | E | F | H |
|---|---|---|---|---|---|---|---|
| `X` | `-2` | `-3` | `0` | `3` | `2` | `-2` | `2` |
| `Y` | `-4` | `0` | `4` | `0` | `-4` | `0` | `0` |

- Окно вывода: `D_w=(100, 200, 400, 500)` → `Δ x_w=300, Δ y_w=300`.
- Габариты фигуры: `x_L=-3, x_H=3\RightarrowΔ x=6`; `y_L=-4, y_H=4\RightarrowΔ y=8`.
- Коэффициенты: `k_x=300/6=50, k_y=300/8=37.5`.
- Оконные координаты вершин (результат расчёта в MathCad):

```
A→(150,500), B→(100,300), C→(250,100), D→(400,300), E→(350,500), F→(150,300), H→(350,300).
```

- Построить фигуру в МСК и в окне `D_w`.

## Задание 2 — график функции


```
f(x)=sin(π x)√|x|, x∈[-6; 6], Δ x=0.1.
```


- Массивы: `X[i]=x_1+i Δ x, Y[i]=f(X[i]), i=0,...,N` (`N=120`).
- Габариты: `x_L=-6, x_H=6\RightarrowΔ x=12`; `y_L≈-2.345, y_H≈2.345\RightarrowΔ y≈4.690`.
- Окно вывода: `D_w=(100, 200, 800, 900)` → `Δ x_w=700, Δ y_w=700`.
- Коэффициенты: `k_x=700/12≈58.33, k_y=700/4.690≈149.24`.
- Сформировать `T` (`Tsw`), получить `X_w, Y_w`, построить график в `D_w`.

## Связь с GDI Windows (гл. 6)

Логические и физические координаты связаны (6.1):

```
x_viewport = x_ViewOrg + (x_window - x_WinOrg) * x_ViewExt / x_WinExt,   y_viewport = y_ViewOrg + (y_window - y_WinOrg) * y_ViewExt / y_WinExt.
```

Если положить `x_WinExt=Δ x, x_ViewExt=Δ x_w, y_WinExt=Δ y, y_ViewExt=-Δ y_w, x_WinOrg=x_L, x_ViewOrg=x_L^w, y_WinOrg=y_L, y_ViewOrg=y_H^w`, то пересчёт можно возложить на GDI в режиме `MM_ANISOTROPIC` (`SetMapMode`, `SetWindowExt`, `SetViewportExt`).
