## Структура

- `lectures/` — лекции.
- `labs/` — задания лабораторных работ.
- `labN/` — решения и рабочие материалы по конкретным ЛР.
- `helper/` — рабочие материалы к лабам (Mathcad, C++), вопросы к зачёту.
