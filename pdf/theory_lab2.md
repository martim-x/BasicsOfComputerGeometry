# Теория для ЛР 2: пересчёт мировых координат в оконные

## 0. Системы координат (из лекций, гл. 7.1)

В компьютерной графике используются несколько систем координат. Для ЛР 2 нужны четыре:

### 0.1 Декартова (прямоугольная) система координат
Две (на плоскости) или три (в пространстве) взаимно перпендикулярные оси с общим началом O. На плоскости: `P = (x, y)`; в пространстве: `P = (x, y, z)`. Оси: OX — абсцисс, OY — ординат, OZ — аппликат. Правая система: при повороте `i → j` на π/2 вектор `k` совпадает с поступательным движением винта с правой резьбой.

### 0.2 Полярная система координат (2D)
Точка P определяется парой `(r, φ)`: `r` — полярный радиус (`r ∈ [0, ∞)`), `φ` — полярный угол (азимут), отсчитываемый от полярной оси OS против часовой стрелки (`φ ∈ (−π, π]` или `[0, 2π)`). Связь с декартовыми (7.1.1):
```
x = r·cos φ
y = r·sin φ
```

### 0.3 Сферическая система координат (3D)
Точка P определяется тройкой `(r, φ, θ)`: `r` — расстояние от начала координат до P (`0 ≤ r < ∞`); `φ` — угол между OX и проекцией OP на плоскость XOY (`0 < φ ≤ 2π`); `θ` — угол между OZ и отрезком OP (`0 ≤ θ ≤ π`). Связь с декартовыми (7.1.2):
```
x = r·sin θ·cos φ
y = r·sin θ·sin φ
z = r·cos θ
```

### 0.4 Мировая / оконная (физическая) / логическая системы координат
- **Мировая (МСК)** — описывает истинное положение объектов; координаты (x, y) (2D) или (x, y, z) (3D).
- **Оконная (экранная, физическая)** — система устройства вывода: начало в левом верхнем углу, X вправо, Y вниз, единица — пиксел.
- **Логическая** — координаты, передаваемые в GDI; единицы зависят от режима отображения (MM_TEXT, MM_LOMETRIC, MM_ANISOTROPIC и т.д.).

Переход между мировой и оконной — предмет ЛР 2 (см. ниже). Переход логических в физические выполняет GDI по формуле (6.1).

## 1. Две системы координат

- **Мировая система координат (МСК)** — описывает истинное положение объектов в пространстве с заданной точностью. Координаты трёхмерные (X, Y, Z), но для плоских изображений используются 2D-координаты (x, y).
- **Оконная (экранная) система координат** — система координат устройства вывода (экрана/принтера), в которой осуществляется вывод изображения. Начало — в левом верхнем углу окна, ось X направлена вправо, ось Y — вниз, единица длины — пиксел.

## 2. Постановка задачи пересчёта

Пусть на плоскости P задана прямоугольная область **D** в мировых координатах с границами:
- `x_L, x_H` — левая/правая граница по X;
- `y_L, y_H` — нижняя/верхняя граница по Y.

В оконной системе задана прямоугольная область **D_w** с границами:
- `x_L^w, x_H^w` — левая/правая граница по X (пикселы);
- `y_L^w, y_H^w` — верхняя/нижняя граница по Y (пикселы).

Для точки M(x, y) в МСК её образ M_w(x_w, y_w) в оконной системе находится из пропорций (5.1)–(5.2):

```
(x_w - x_L^w) / (x_H^w - x_L^w) = (x - x_L) / (x_H - x_L)
(y_H^w - y_w) / (y_H^w - y_L^w) = (y_H - y) / (y_H - y_L)   // инверсия Y
```

## 3. Обозначения

- `Δx_w = x_H^w − x_L^w` — ширина области вывода в оконных координатах (пикселы);
- `Δx = x_H − x_L` — ширина области в мировых координатах;
- `Δy_w = y_H^w − y_L^w` — высота области вывода в оконных координатах;
- `Δy = y_H − y_L` — высота области в мировых координатах.

Масштабные коэффициенты:
```
k_x = Δx_w / Δx
k_y = Δy_w / Δy
```

## 4. Формулы пересчёта (5.4)

```
x_w = k_x · (x − x_L) + x_L^w
y_w = −k_y · (y − y_L) + y_H^w       // минус — инверсия оси Y
```

## 5. Матричная форма (5.5)–(5.9)

В однородных координатах:

```
V_w = T · V
```

где

```
V_w = [ x_w  y_w  1 ]^T
V   = [ x    y    1 ]^T
T   = | k_x   0    x_L^w − k_x·x_L |
      | 0    −k_y  y_H^w + k_y·y_L  |
      | 0     0            1          |
```

(в MathCad в лабе матрица `Tsw` именно такая: diag(kx, −ky), третий столбец — смещения).

## 6. Связь с GDI Windows (гл. 6)

Физические координаты (пикселы экрана) и логические (передаются в GDI) связаны (6.1):

```
x_viewport = xViewOrg + (x_window − xWinOrg)·(xViewExt / xWinExt)
y_viewport = yViewOrg + (y_window − yWinOrg)·(yViewExt / yWinExt)
```

Если положить:
```
xWinExt = Δx,   xViewExt = Δx_w,
yWinExt = Δy,   yViewExt = −Δy_w,
xWinOrg = x_L,  xViewOrg = x_L^w,
yWinOrg = y_L,  yViewOrg = y_H^w,
```
то пересчёт мировых → оконных можно возложить на GDI в режиме `MM_ANISOTROPIC` (через `SetMapMode`, `SetWindowExt`, `SetViewportExt`).

### Задание 1 — фигура ABCDE (и F, H)
Координаты вершин:
| точка | A | B | C | D | E | F | H |

| X | −2 | −3 | 0 | 3 | 2 | −2 | 2 |
| Y | −4 | 0 | 4 | 0 | −4 | 0 | 0 |

1. Построить фигуру в МСК.
2. Задать окно вывода `D_w = (100, 200, 400, 500)` (x_L^w=100, y_L^w=200, x_H^w=400, y_H^w=500).
3. Определить границы мировой области по габаритам фигуры:
   - `x_L = min(X) = −3`, `x_H = max(X) = 3` → `Δx = 6`;
   - `y_L = min(Y) = −4`, `y_H = max(Y) = 4` → `Δy = 8`.
4. Вычислить `k_x = 300/6 = 50`, `k_y = 300/8 = 37.5`.
5. Сформировать матрицу `Tsw` и получить оконные координаты вершин `Xw, Yw` (в лабе результаты: A→(150,500), B→(100,300), C→(250,100), D→(400,300), E→(350,500), F→(150,300), H→(350,300)).
6. Построить фигуру в окне.

### Задание 2 — график функции
`f(x) = sin(πx)·√|x|`, `x ∈ [−6; 6]`, шаг `Δx = 0.1`.

1. Сформировать массивы `X[i] = x1 + i·Δx`, `Y[i] = f(X[i])`, `i = 0..N` (N = 120).
2. Найти габариты: `x_L = −6, x_H = 6 → Δx = 12`; `y_L ≈ −2.345, y_H ≈ 2.345 → Δy ≈ 4.690`.
3. Окно вывода `D_w = (100, 200, 800, 900)` → `Δx_w = 700, Δy_w = 700`.
4. `k_x = 700/12 ≈ 58.33`, `k_y = 700/4.690 ≈ 149.24`.
5. Сформировать `Tsw`, получить `Xw, Yw`, построить график.

## 8. Итоговая «общая сигнатура» (универсальная формула)

Для любой задачи пересчёта мировых 2D-координат в оконные:

```
Дано:
  D   = (x_L, y_L, x_H, y_H)        — область в МСК (по габаритам объекта)
  D_w = (x_L^w, y_L^w, x_H^w, y_H^w) — область окна вывода (пикселы)

Шаг 1. Δx = x_H − x_L ;  Δy = y_H − y_L
        Δx_w = x_H^w − x_L^w ;  Δy_w = y_H^w − y_L^w

Шаг 2. k_x = Δx_w / Δx ;  k_y = Δy_w / Δy

Шаг 3. T = [[ k_x,   0,   x_L^w − k_x·x_L ],
            [ 0,   −k_y,  y_H^w + k_y·y_L ],
            [ 0,     0,            1        ]]

Шаг 4. (x_w, y_w) = ( k_x·(x−x_L)+x_L^w ,  −k_y·(y−y_L)+y_H^w )

Шаг 5. Построить объект по (x_w, y_w) в D_w.
```

Ось Y инвертируется (−k_y), т.к. в МСК Y растёт вверх, а в оконной системе — вниз.
